# 视频分镜演示动画（每镜头一个 HTML）

一个镜头 = 一个独立 HTML，统一播放器底盘 + 每页一种完全不同的视觉风格，全屏录屏即成片。内容开放（技术实测/产品发布/课程/叙事皆可），不变的是电影化机制、镜头语言与完成度标准。

## 创作哲学

1. **风格轮换**：连续镜头绝不同风格。问"这段内容若是一件实物/一个场所，它是什么"——复古报纸、POS 小票、审讯室、像素游戏……把抽象内容**具象成一个世界观**，页面就活了。
2. **禁默认科技暗色**：黑底+霓虹+玻璃拟态的"乌漆墨黑油光锃亮"两页即疲劳，除非内容本身是终端主题。
3. **想象力优先**：底盘之上放开写——会砸下的印章、会掉进存钱罐的硬币，用户要惊喜感。
4. **完成度是纪律**：元素有入有出（或定格）、无重叠遮挡、无孤儿元素、结尾有重播暗示、数据有出处角注。
5. **音画同步**：关键动作有音效、镜头移动配 whoosh；安静也是设计。

## Token 纪律（硬性）

- **禁止通读** `assets/template.html`（含大量底盘代码）。
- 模板一律 `cp` 复制后**只读标记区域**（见第 1 步的行号地图）。
- 机制与风格知识优先取自 `references/` 三份浓缩文档（mechanics / style-cards / examples），不要现场读源码反推。

## 工作流

**第 0 步 · 输入与风格分配表**：通读素材（大纲/口播稿/画面设计/口述），拿到分镜列表 + 口播时间戳（时间轴对齐基准）。排表 `镜头|时长|视觉风格|字体组合|主色`：相邻不同风格、整辑不重复、**同一实体全系列锁同一颜色**（观众靠颜色跨页追踪）。表给用户确认后再动工。若无分镜，先为素材切分镜头（每个 8–15s 一段，标记口播起止）。

**第 1 步 · 逐页实现**（cp 起步，只读标记区）：

```bash
cp assets/template.html "<输出目录>/shot-<章节>-<序号>_<名称>.html"
node scripts/markmap.js "<输出目录>/shot-<章节>-<序号>_<名称>.html"   # 打印"改这里"行号地图 + DUR 行
```

用 Read 的 offset/limit 只读标记行附近区域，逐一替换：① 字体与配色（Google Fonts 与本地衬线体二选一，见 references/style-cards.md）；② 重画画面层；③ 按口播时间戳写 cue（注释引用口播句，如 `// 0:15「这句话对应画面」`）；④ `DUR`=规定时长±0.5s。底盘（虚拟时钟/音效引擎/时间轴/镜头调度/HUD）不动。

**第 2 步 · 质检与出片**：

```bash
node scripts/probe.js "<页面>" <毫秒> [输出.png]        # 定格截帧（毫秒可逗号列表）；查重叠/穿帮/收尾
node scripts/probe.js "<页面>" 600,1800,3000,4200,6000 --sheet   # 一屏总览的接触表（推荐先跑这个）
node scripts/render.js "<页面或镜头目录>"                # 出 mp4（默认 1920×1080, 30fps）
node scripts/render.js "<目录>" --scale=0.5              # 快速试片；--quality=23 更小
```

**渲染模式**：默认 `deterministic`（逐帧 `__vtick` 定格 + 逐帧截图）。它与视频时长无关、不可能丢帧、同输入必得同输出（已实测：同镜头连渲两次 mp4 的 SHA256 完全一致）；老的实时抓帧模式保留为兜底（`--realtime`），但它耗时≈视频时长且长片有丢帧风险。**优先用默认模式**；只有当页面没有继承模板底盘（缺 `__vtick`）时才退回 `--realtime`。

**写动画时的取舍（影响可复现性）**：`tween()`/`on()` 由虚拟时钟驱动，**天生可定格，优先用**；CSS `transition`/`@keyframes` 走浏览器真实时钟，虽然有 `__seekCss` 兜底，但**无限动画无法定格**（会被停用），所以关键节拍别用无限动画。详见 `references/mechanics.md`。

probe 会注入 0s 过渡并用 `__vtick(ms)` 把页面定格到任意时间点，同一毫秒多次截图结果一致，且会先等字体文件真正就绪（否则会拍到 fallback 字体、漏掉 CJK 缺字）；对裸 `requestAnimationFrame` 自定义动画，probe 会等其收敛到终态。probe 与 render 默认带 `?noboot=1&nohud=1`，避免拍到启动遮罩和冻结在 00:00 的 HUD。工具路径可用 `PLAYWRIGHT_HOME` / `FFMPEG_PATH` 环境变量覆盖。

**必做**：先跑 `--sheet` 接触表一眼扫完所有镜头，再逐镜头看细节；最后对渲染出的 mp4 做程序化核验（时长与 DUR 是否一致、文件大小、首帧是否为非空画面）。

**第 3 步 · index 总览**：按章节分组的导航卡（编号/时长/标题/风格标签），自成一种风格，双击可打开各镜头。

**翻新已有页面时**：先盘点并列清单（用户点名保留的页面一字不动）→ 底盘统一注入 → 逐页重设计画面层 → 补镜头/音效 cue → 质检。

## 交付标准

- [ ] 黑场「启动播放」起手，渐变后开演；画面分辨率默认 1920×1080 16:9（或按用户给定比例）；HUD 可唤出；可暂停重播；DUR 准确
- [ ] 相邻镜头风格/字体/配色不同；无默认科技暗色；emoji→内联扁平 SVG
- [ ] **每镜只表达一个动效概念 + 一种情绪**；全辑情绪单向推进，不来回跳（见 references/style-cards.md「动效与节奏」）
- [ ] 关键节拍有镜头运动（推/拉/跟/摇）+ whoosh；关键动作有音效；计数滚动有连击键音
- [ ] **关键帧留驻**：主揭晓、盖章、结论这类重点有 0.5–1s 的停顿，不是一晃而过
- [ ] 无底部字幕条（口播只以 cue 注释对齐，不上屏）；接触表 + 截图验证无重叠遮挡；数据角注出处；index 可逐页打开
- [ ] 渲染产物：每镜头一个 `<镜头名>.mp4`，时长与 DUR 一致（±0.5s），能正常播放
- [ ] 复刻真实软件界面时**用真实页面截图**，不手搓 UI 近似（手搓只能做非复刻型的风格化场景）
