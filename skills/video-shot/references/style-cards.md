# 风格卡片（40 种 · 选型即查）

## 核心方法

> 这段内容如果是一件实物或一个场所，它是什么？

让页面的材质、排版、动效都服从这个"世界观"。抽象概念一旦被具象成一个熟悉物件，观众立刻有"惊喜感"，也最容易做出差异化。卡片是起点，不必照抄；写完可对照 UP 样板页号做局部抽查。

## 一票否决项（反模式）

- 默认科技暗色：黑底、霓虹、玻璃拟态（除非内容本身是终端主题）。
- 用 emoji 当正式图标（换内联扁平 SVG）。
- 全程居中对称、没有非对称元素（每页 ≥1 处非对称/超大字/出血）。
- 静态常驻元素没有任何微动效。
- 纸感风格没有纸纹、网点、锯齿边、咖啡渍等材质。

## 图标规范

内联扁平 SVG，描边 `2–3px`、圆头，每页约 `4–10` 枚。不要 emoji。

## 字体公式

```
展示拉丁字 + 中文字族 + 数据等宽字体
```

- 中文打底二选一：`Noto Sans SC`（400/700/900）或 `Noto Serif SC`。
- 优先从 Google Fonts 引入；离线时退回系统字体（`Microsoft YaHei` / `Songti SC`），保证录制环境可渲染。
- 数字和表格用等宽字体 + `tabular-nums`。
- 大标题字距 `+2–4px`；英文小标字距 `3–8px` 作装饰线。
- 印刷风可用硬偏移阴影：`box-shadow: 8px 8px 0 rgba(0,0,0,.15)`。

## 动效与节奏（硬规则）

**每镜只表达一个动效概念 + 一种情绪。** 一种动效手法（弹出/盖章/翻页/推进/擦除/闪烁）全片只当一次主视觉，重复镜头、重复 tagline 一律删。运动做单向推进：历史/反差 → 紧张/冲突 → 释放/落定，**不来回跳**。

**节奏表**（把这张表的数值写进 `on(ms, …)` 的 cue 里）：

| 环节 | 时长 | 要点 |
|---|---|---|
| 微状态留驻 | ≤1s | 悬停、按下、加载这类小状态点到为止 |
| 批量元素入场 | 0.5s | 列表/卡片组用 stagger 错开，单个 duration ≤0.5s |
| 主揭晓 | 动作 0.45–0.6s + **留驻 0.5–1.0s** | 数字揭晓、盖章、结论：**推近 + ding + 停顿**，缓出（`1-(1-k)^3`） |
| 正片主体 | ≈3s | 单镜信息主体，8–15s 的镜头里可放 2–3 组 |
| 收尾 | 1s | 重播暗示 + 定住 |

**进出场**：元素「有入有出」——入场要有来源（从哪冒出来的），出场要么离开画面、要么明确定格收尾，不留孤儿元素。

**缓动**：默认 `ease-out`（`1-(1-k)^3` 是模板 `tween` 的默认曲线）。冲击类用更陡的 `ease-out`（0.45–0.6s），机械/指针类用轻微 `ease-in-out`。**不要用线性**跑主要运动，会显得廉价。

**镜头运动与内容匹配**：数字揭晓/盖章/结论→推近；新面板入场前→拉回全景；主体逐站出现→跟拍 `camFocus`；标题卡→Ken Burns 缓推；高潮瞬间→0.45–0.6s 快推再拉回（见 `mechanics.md` 的镜头调度）。

**音画对齐**：音效与视觉 cue 同帧（误差 ±50ms）；**每秒不超过 2–3 个主要音效**，段落之间留 ≥0.5s 静默——安静也是设计。

## 完成度检查表（每镜头过一遍）

- 元素有入场、有退场或定格收尾——没有"孤儿元素"。
- 无重叠遮挡（probe 截图验证）。
- 结尾有重播暗示（如「重播 ↻」）。
- 关键数据带出处角注。
- 相邻镜头风格/字体/配色不同且全辑不重复。
